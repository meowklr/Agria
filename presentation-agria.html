Fonctionnalité clé

Diagnostic IA en 3 étapes

Notre moteur IA croise les symptômes observés avec les données météo locales pour diagnostiquer et recommander des traitements en temps réel.

1

Choisir la culture

Blé, maïs, tournesol, colza ou vigne — sélectionnez votre type de culture parmi les options.

2

Observer les symptômes

Jaunissement, taches, flétrissement, insectes, pourriture — décrivez ce que vous observez.

3

Localiser la parcelle

Renseignez votre ville pour enrichir le diagnostic avec les conditions météo locales en direct.

✓

Résultat IA

Diagnostic précis et recommandations de traitement personnalisées générées instantanément.

Visualisez vos parcelles sur une carte

Tracez et gérez vos parcelles directement sur la carte interactive. Un code couleur intuitif révèle l'état de santé de chaque champ en un coup d'œil.

  • Parcelles géolocalisées

    Délimitez vos champs directement sur la carte et retrouvez-les instantanément.

  • Code couleur santé

    Vert = bonne santé, orange = surveillance, rouge = intervention urgente requise.

    Affichez la culture, la surface et le statut de chaque parcelle en surimpression.

Stack technique

Construit avec des technologies robustes

🗄️

Supabase

Backend as a service : authentification sécurisée, base PostgreSQL, stockage de fichiers et gestion complète des données d'exploitation.

🧠

Intelligence Artificielle

Moteur de diagnostic expert croisant symptômes observés et données météo locales pour des recommandations agronomiques précises.

🌤️

API Météo

Intégration d'une API météo externe : température, humidité, prévisions 5 jours, recherche par ville en temps réel.

🗺️

Cartographie

Carte interactive pour visualiser, délimiter et gérer les parcelles avec géolocalisation et tracé de zones personnalisé.

📱

PWA Mobile First

Progressive Web App avec meta theme-color, bottom navigation, viewport adapté et design 100% responsive dès 320px.

🎨

Design System

Cormorant Garamond + Plus Jakarta Sans. Palette naturelle, animations reveal, cartes glassmorphism pour une expérience premium.
