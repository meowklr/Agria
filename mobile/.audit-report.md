## Pass 1 — Bugs corriges (5 corrections)

### `app/(tabs)/carte.tsx`
- **BUG** : Le bouton "Localiser" etait non fonctionnel (onPress vide).
  **Cause** : Placeholder non implemente — la fonction `loc()` existe dans le JS de la WebView mais n'etait jamais appelee.
  **Correction** : Ajout de `pm({ type: 'loc' })` + haptic feedback sur le bouton.

### `src/services/diagnostic.ts`
- **BUG** : `fetchOpenMeteo()` appelait `fetch()` sans AbortController — pas de timeout, risque de blocage indefini.
  **Cause** : Oubli du pattern `fetchWithTimeout` present dans `weather.ts`.
  **Correction** : Ajout d'un AbortController avec timeout 10s, identique au pattern de `weather.ts`.

### `app/(tabs)/diagnostic.tsx`
- **BUG** : `fetch(webhookUrl)` pour l'envoi du diagnostic a Make.com sans AbortController — pas de timeout.
  **Cause** : Meme oubli que ci-dessus.
  **Correction** : Ajout d'un AbortController avec timeout 10s + `clearTimeout` apres la reponse.

### `src/hooks/useWeather.ts`
- **BUG** : La chaine de dependances `useEffect → refresh (useCallback dependant de city) → useEffect dependant de city` etait fragile — `refresh` non liste dans les deps de l'effet, ce qui pouvait causer des appels stale.
  **Cause** : Violation de la regle `exhaustive-deps` — le useEffect utilisait `refresh()` mais ne listait pas `refresh` comme dependance.
  **Correction** : Inlining de l'appel `Promise.all` directement dans le useEffect, ne dependant que de `city`. La fonction `refresh` exportee reste disponible pour les rafraichissements manuels.

### `src/components/NotificationBell.tsx`
- **BUG** : `setInterval(reload, 5000)` recreait et detruisait l'intervalle a chaque render car `reload` changeait de reference.
  **Cause** : `reload` = `load` (non memoise dans `useNotifications`) — nouvelle reference a chaque render → intervalle recree a chaque cycle.
  **Correction** : Utilisation d'un `useRef` pour stabiliser la reference de `reload`, intervalle cree une seule fois au montage.

## Points d'attention manuels

1. **`auth.ts:71`** — Parametre `_email` inutilise dans `changePassword()`. La fonction utilise `user.email` de l'instance auth. Si le caller passe un email different, il est ignore silencieusement. **Suggestion** : verifier que `_email` correspond a `user.email`, ou le supprimer de la signature.

2. **`auth.ts:81`** — Parametre `_oldEmail` inutilise dans `updateEmail()`. Meme remarque.

3. **`src/types.d.ts`** — Ne declare que `expo-image-picker`. Si d'autres modules sans types sont ajoutes, ce fichier devra etre enrichi.

4. **`carte.tsx` HTML inline** — Le code Leaflet (~60 lignes) est inline dans une string template. Pour la maintenabilite a long terme, un fichier HTML separe serait plus lisible (mais le pattern actuel est fonctionnel).

5. **Duplication `labelCulture()`** — La meme fonction existe dans `useDiagnostic.ts:8-10` et `diagnostic.tsx:17-20`. **Suggestion** : extraire dans un module partage (`src/data/cropData.ts` ou `src/utils/labels.ts`).
