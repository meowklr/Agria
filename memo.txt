Nous travaillons sur l'app mobile Agria située dans :
\agria\mobile\
Le projet est une app agricole (React Native/Expo) nommée Agria,
avec Firebase Realtime DB + Auth et Make.com pour l'automatisation.
La palette réelle de l'app est dans mobile/src/theme/index.ts.
Architecture :
- mobile/app/ → pages Expo Router (tabs: dashboard, carte, diagnostic, profil + admin + login)
- mobile/src/components/ → composants UI (Badge, Button, Card, Input, Typography, etc.)
- mobile/src/services/ → logique métier (auth, weather, diagnostic, champs, alerts, firebase)
- mobile/src/hooks/ → hooks custom (useAlerts, useChamps, useDiagnostic, useWeather, etc.)
- mobile/src/data/ → données statiques (config, cropData)
Stack technique :
- React Native 0.81.5, Expo SDK 54, TypeScript 5.9
- Expo Router (file-based routing), react-native-reanimated, react-native-gesture-handler
- Polices : Fraunces (serif), Outfit (sans-serif) via @expo-google-fonts
- APIs : OpenWeatherMap, Open-Meteo, Nominatim (geocoding)
- Design : warm earth tones (#E8B84B primary, #FDF8EE bg, #3D2E1F text)
Skills disponibles :
- brainstorming : exploration du besoin avant toute implémentation
- test-driven-development : TDD, écrire les tests avant le code
- systematic-debugging : débogage méthodique étape par étape
- writing-plans / executing-plans : planification + exécution multi-étapes
- verification-before-completion : toujours vérifier avant de déclarer fini
- frontend-design : design mobile distinctif et créatif
- emil-design-eng : polish UI, micro-interactions, animations (Emil Kowalski)
- design-motion-principles : audit motion design (Kowalski, Krehel, Tompkins)
- web-animation-design : animations et transitions (CSS, Framer Motion, GSAP)
